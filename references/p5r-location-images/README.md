# Persona 5 Royal location image references

这是一套仅用于生图参考的 P5R 地点场景截图，不参与网站构建，也不会被部署到 GitHub Pages。

## 目录

- `station-menu/`：车站菜单、东京线路图、区域地图
- `yongen-jaya/`：四轩茶屋 / Café Leblanc
- `shibuya/`：涩谷中央街、地下通路、车站广场
- `kichijoji/`：吉祥寺商店街
- `shinjuku/`：新宿街区
- `akihabara/`：秋叶原电器街
- `ichigaya/`：市ヶ谷钓鱼池
- `kanda/`：神田教会
- `shinagawa/`：水族馆
- `odaiba/`：海滨公园

文件统一转换为 PNG，方便直接拖入生图工具作为参考图。来源和原始链接记录在 `sources.json`。

这些图片只作为个人项目的视觉研究素材使用；如果后续要公开发布或用于网站内容，应换成自己的截图、照片或取得相应授权。
